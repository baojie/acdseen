## Why it mattered

**Why do this?**

I wanted a tool that opens and shows the picture. Every image viewer still
maintained descends from ACDSee 3.0, the release that started piling on tags,
EXIF panels, editing, batch processing and plugins. This project reproduces the
restraint of 1.2x instead.

**What problem does it solve?**

Two: slowness — a modern viewer takes seconds to start and makes you wait on
every page turn — and clutter, having to get past a wall of panels to look at
one image. The two-stage decode, the pre-read and the thumbnail thread pool
address the first; the deliberately narrow feature set addresses the second.

**What does it change about the deliverable?**

One day took the repo from empty to an application usable daily: browsing,
preview, viewing, slideshow and file operations all working, the Win95 look in
place, and both the test suite and the threading rule (three tests exist solely
to hold that line) established alongside it.
